# Pack v8 — Streamlit 'Data Science Pro App'

Ce pack transforme le v7 en **application pro** (multi-pages) :
- Home (Mode Démo Prof + KPI)
- Data (upload/preview)
- Train & Evaluate (boutons pipeline)
- Résultats (dashboard KPI + plots)
- Reco Live Demo (simulation + rappel ms-user)
- Export & DB (saisie manuelle + push MySQL optionnel)
- Runs (historique d'exécutions + artefacts)

## Lancer
```bash
cd sakiga_ds_deliverable
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```
